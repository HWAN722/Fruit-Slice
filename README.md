# 拼音汉字切水果（语音版）

一个在浏览器里玩的识字游戏：水果从屏幕下方抛起，每个水果上写着一个**拼音**或**汉字**，对着麦克风**读出来**，读对了水果就被切开。

适合正在学拼音、认字的小朋友，也适合学中文的外国学习者。

## 玩法

- 在菜单里选择**玩法**（拼音 / 汉字 / 混合）、**字库**（可多选，也可以粘贴一段文字作为自定义字库）和**难度**
- 点"开始游戏"（或按 Enter），允许浏览器使用麦克风
- 读出水果上的拼音或汉字，读对就切开，得 10 分
- 一次读出多个字（如"妈妈爸爸"）可以连着切；同时切开多个有**连击**加分
- 屏幕上有好几个同音的水果时，一次全部切开
- 水果掉出屏幕没被切到，扣一条命；3 条命用完游戏结束
- 结算页显示正确率、最常读错的声调，并列出**没切到的字**和拼音；点一下汉字可以听读音
- 掉一条命后难度会稍微往回退，不会越错越难

没有麦克风或浏览器不支持语音时，可以在下方输入框**打字**：拼音（`ma1` 或 `mā`）或汉字，按 Enter。

### 快捷键

| 按键 | 作用 |
|---|---|
| Enter | 开始 / 再玩一次 |
| Esc | 暂停 / 继续；关闭设置 |
| M | 暂停或结束时回到菜单 |

手机、平板上用屏幕右上角的暂停按钮。
| F2 | 打开语音诊断面板（也可以在网址后加 `?debug`） |
| F3 | 切换识别模式：持续识别 / 单句模式 |
| F4 | 开关"快速断句" |

## 运行

需要 [Node.js](https://nodejs.org/) 18 或更高版本。

```bash
npm install
npm run setup:model   # 下载离线识别模型（约 42MB，只需一次）
npm run dev           # 打开 http://localhost:5173
```

模型会放在 `public/models/`（不提交到 git）。

其他命令：

```bash
npm run test     # 单元测试（Vitest）
npm run lint     # ESLint + TypeScript 类型检查
npm run build    # 生产构建，输出到 dist/
```

> 浏览器只允许在 `localhost` 或 HTTPS 下使用麦克风。部署到线上时需要 HTTPS。

## 语音识别

设置里可以选两种识别引擎：

| 引擎 | 说明 |
|---|---|
| **离线识别**（默认） | 用 [Vosk](https://alphacephei.com/vosk/) 中文小模型在浏览器里本地运行，不联网、国内也能用；首次加载约 42MB，之后浏览器会缓存。小模型比在线识别容易认错字，读词语比读单字准 |
| 浏览器自带 | Web Speech API。Chrome 走 Google 服务（国内通常不可用），Edge 走微软服务 |

离线识别支持桌面版 Chrome、Edge 等现代浏览器；不支持语音的浏览器会自动改用键盘输入。

### 识别慢怎么办（浏览器自带识别）

浏览器的识别引擎常常要等一段静音才给出结果，读单个字时尤其明显。默认开启了**快速断句**：自己检测音量，听到你说完就让引擎立刻出结果。

如果还是慢，按 F2 打开诊断面板，看"说完 → 出字"的毫秒数，再用 F3 / F4 换几种设置对比。

## 设置

菜单里的"设置"可以调整以下内容，设置会保存在浏览器里：

- 声调匹配（关闭 / 字形推断 / 音高分析）、是否显示声调符号、变调、校准音域
- 严格汉字匹配、模糊音规则
- 是否出现炸弹、音效和音量
- 识别引擎（离线 / 浏览器自带）、识别模式、快速断句

## 匹配规则

- **按拼音比对**：读"妈"被识别成"吗""麻"也算对（同音字），可在设置中改为严格匹配汉字
- **多音字**：水果"长"读 cháng 或 zhǎng 都算对
- **声调**（默认关闭）：可选"字形推断"（按识别出的字的声调）或"音高分析"（直接分析声音的音高变化）；读对音节、读错声调时水果不切开，并提示 `你读的是 má，应该是 mā`
- **变调**：词语按实际读音判断，如"你好"读 ní hǎo
- **模糊音**（默认关闭）：z/zh、c/ch、s/sh、n/l、f/h、an/ang、en/eng、in/ing，可单独开关
- **炸弹**（可选）：只读到炸弹上的字会扣命；同时读到水果和炸弹时优先切水果，不扣命

## 技术栈

- Vite + TypeScript（strict）
- 原生 Canvas 2D 渲染，美术全部用代码绘制；音效用 Web Audio 实时合成，没有音频文件
- 语音识别：Vosk（vosk-browser，离线）/ Web Speech API
- [pinyin-pro](https://github.com/zh-lx/pinyin-pro)：汉字转拼音
- Vitest 单元测试
- 无后端，设置和最高分保存在 `localStorage`


### 字库格式

```json
{
  "id": "grade1-up",
  "name": "一年级上册",
  "type": "hanzi",
  "items": [
    { "text": "妈", "pinyin": ["mā"] },
    { "text": "长", "pinyin": ["cháng", "zhǎng"] }
  ]
}
```

`pinyin` 是数组，多音字写多个读音；词语的音节用空格分开，如 `"nǐ hǎo"`。

### 声调：字形推断 vs 音高分析

- **字形推断**看识别出来的字是几声。读词语、句子时还行，但单读一个音时识别引擎经常给出"啊、哦、衣"这类多音字，**分不出声调**（读哪个声调都返回"啊"）。
- **音高分析**直接听声音的高低变化：YIN 算法提取基频 → 按音量切音节 → 按曲线的起点、终点、最低点和起伏判断声调。练单韵母、单字声调请用这一档。第一次使用会请玩家读"妈 麻 马 骂"校准音域。

声调分类用 `tests/fixtures/tones/` 下的标准四声录音做离线测试（目前准确率 88.9%，要求 ≥ 85%）。这些录音是 Windows 自带中文语音合成的（正常、调高、调低三套），**还没有真人录音**，真人尤其是儿童的声音可能需要再调阈值。

M7 还没做的：错误提示里的音高曲线小图、真人（男声、女声、童声）录音测试、手机上同时占用麦克风的实测。
